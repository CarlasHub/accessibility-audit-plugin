      Privacy, permissions, and cost

      This browser saves your website address or manual page list, destination, and repository. Discovery temporarily checks public pages on the starting URL’s exact origin and does not save its secure selection token.

      The connector configures the workflow but never runs audits or stores reports. GitHub Actions usage, history, and reports belong to the repository owner—not CarlasHub. Public-repository runs on GitHub-hosted runners are free; private-repository usage follows the owner’s GitHub plan and limits.

      Honest by design

      All 55 WCAG 2.2 Level A and AA criteria stay accountable.

      Every report pairs selective automated evidence with one criterion-specific human procedure and an evidence prompt. Untested, partial, or inconclusive work stays visible and never becomes an automatic pass or certification claim.

      ⌁

      Evidence-led browser checks

      Chromium runs by default, with optional Firefox and WebKit coverage. Checks include semantics, names, contrast signals, structure, component states, links, 200% text resize, 320px reflow, and configurable keyboard, form, focus, and live-region journeys. Unresolved tool results become review work; bounded checks disclose partial coverage.

      ▦

      Review-ready, trackable outputs

      An executive summary and prioritised actions lead the accessible HTML report. Standard A/AA results stay separate from supplemental and optional AAA advice. Consolidated remediation items retain their page, viewport, state, and selector occurrences across Excel, JSON, CSV, SARIF, screenshots, and ZIP exports.

      ◎

      Human decisions remain explicit

      No automated tool can certify WCAG conformance. Screen-reader experience, meaning, usability, and exceptions still require qualified review.
