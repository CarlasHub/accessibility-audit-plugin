# Manual verification

After every run:

1. Confirm the workbook auditor and requested URLs.
2. Confirm the completed, partial, not-started, and skipped page counts.
3. Confirm every Accessibility Report row has the expected populated fields and no placeholder id.
4. Keep confirmed failures, review items, blockers, and manual checks separate.
5. Review a sample of Image Inventory previews against the page, viewport, rule, selector, and JSON evidence.
6. Confirm repeated-component rows list every affected page and genuinely share one implementation and root cause.
7. Confirm Notes contains only actionable remediation.
8. Manually verify placeholder/5xx links before treating them as defects.
9. Complete the guided screen-reader, physical-device, keyboard-journey, content, visual, media, cognitive, and exception checks.
10. Re-run after fixes. Do not infer a pass from an absent automated signal.
