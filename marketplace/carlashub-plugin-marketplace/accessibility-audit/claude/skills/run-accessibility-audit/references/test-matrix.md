# Test matrix reference

The engine runs headless desktop, 390px mobile, and 320px reflow checks for HTTP/runtime state, axe, DOM semantics, sampled keyboard traversal, focus signals, disclosure state/relationships/focus order, tab relationships and operation, reflow, text spacing, target sizing, table/media signals, and screenshots. It tries bundled Chromium, Chrome, and Edge, then can install Playwright Chromium once in plugin-owned storage when none is available. Disclosure testing waits for the rendered inventory, excludes hidden/inactive clones, establishes a collapsed baseline, verifies the intended focused control, exercises Enter and Space, waits for JavaScript/animations to settle, and re-queries the control and panel before comparing state and visual visibility in the same snapshot. Accessibility-tree exposure from `aria-hidden`/`inert` is retained separately and cannot be mistaken for CSS-hidden visual content. Unresolved or unsettled evidence cannot become a finding. Missing `aria-controls` alone is not reported. Generic disclosures and accordions are not tested against an Escape-to-close requirement; Escape remains a manual, pattern-specific check for controls such as dialogs and applicable menus or popovers.

Same-origin link validation skips external, download, destructive, logout, and non-HTTP targets. Matching request-context and in-page 404/410 results are confirmed. Placeholder and 5xx results are reviews. Candidate/check counts and configured-limit truncation are retained; truncation is not a pass.

Visible consent banners are dismissed before interaction checks and evidence capture, preferring reject or necessary-only actions. If a modal remains active, the engine records an interaction-coverage blocker and skips underlying disclosure, tab and link interaction checks. The final report retains at most one representative contextual component screenshot per confirmed, blocker, or review reporting unit when capture succeeds. Full-page screenshots are reserved for page-level failures or unresolved blocking surfaces. Manual procedures do not generate screenshot evidence.

JSON retains violations, axe incomplete results, pass-rule counts, related axe nodes, keyboard cycle/truncation/scope and focus samples, incomplete interactions, consent and blocker state, link counts/truncation, and a page/viewport/area coverage matrix. Coverage statuses are confirmed-passed, confirmed-failed, tested-inconclusive, manual-review-required, not-tested, and not-applicable. Empty findings, sampled traversal, incomplete axe rules, ambiguous interactions, and untested states are never represented as findings or passes.

Automation does not prove complete keyboard journeys, supported screen-reader combinations, physical mobile behavior, content meaning, complete visual contrast, media alternatives, timing, flashing, gesture alternatives, consistency, error quality, accessible authentication, or WCAG exceptions.
